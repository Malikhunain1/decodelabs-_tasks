# Sprout – Responsive Habit Garden

A responsive frontend interface built with plain HTML, CSS and JavaScript (no frameworks).

## What it does
- Add daily habits and pick a flower colour for each
- Tap **Water today** to check in; each habit is drawn as a plant that grows with your streak (Seed → Sprout → Leafy → In bloom at 7 days)
- Progress ring shows how many habits are watered today
- Filter by All / To water / Watered
- Day and night theme (follows your system setting by default)
- Data is saved in the browser with localStorage

## Responsive design
- CSS Grid with `auto-fill` columns; 2 columns on phones, 1 on very small screens
- Header, form and buttons reflow at 560px and 380px breakpoints
- Keyboard focus styles, ARIA labels and reduced-motion support

## Run it
Open `index.html` in any browser. No build step needed.

## Skills shown
Frontend development, responsive design, UI basics, DOM manipulation, state with localStorage, inline SVG.
